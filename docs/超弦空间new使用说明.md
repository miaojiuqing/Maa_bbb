# 超弦空间new

面向 MuMu 模拟器的超弦空间任务，在安卓端的周期性任务中选择「超弦空间new」。

## 配队

- 「上方三关配队方案」对应地图左侧、上方、右侧的三个房间。
- 「下方关卡配队方案」对应地图下方的房间。
- 两组分别选择「不更换编队」或 A队、B队、C队、D队。
- 选择预设方案时，程序在方案列表识别队名，点击对应方案，再点击「使用方案」。
- 选择「不更换编队」时，使用游戏配队页当前的队伍。

任务从榜单进入房间地图，选择房间后点击「战斗准备」，进入配队页并应用相应方案，再点击「开始战斗」。

预设方案页上的队名需要与选项一致，例如 `A队`。两组配队可以选择相同方案。

## 出招表

运行所需的 JSON 随 agent 一起打包和热更新。

- 角色文件位于 `agent/custom/profiles/superstring/roles/`。
- 配队文件位于 `agent/custom/profiles/superstring/teams/`。
- 默认携带窈窕谍影基础点按出招表，默认队伍循环武器技能与普攻。
- 角色文件中的 `touch_actions` 使用 1280×720 坐标。
- 队伍文件可以配置 `cycle`，或用 `rotation` 按阶段指定角色、`switch_1` / `switch_2`、持续时间和动作。

超弦空间中的 `switch_1`、`switch_2` 会切换前台队员。新增角色或队伍文件后，还需在任务 JSON 的角色、配队选项中加入对应项目。

## 完成与测试

正常模式下，最后一关有非零分数时判定本期四关完成。「只打前三层」默认关闭，开启后沿用前三个进度关卡的完成判断。

「测试模式」默认关闭，开启后跳过本期完成判断，进入左侧房间测试。

本功能基于上游 `v1.13.22`、提交 `f8784a9` 整理。运行版已验证嵌入式组件加载、MuMu 连接和配队流程，整理后的地图分流已加入自动检查。完整四关实战仍待复测。
