# win32 端图片适配清单

桌面端（`resource_win32` / `resource_win32_jp`）对 base 的覆盖是"按节点名"和"按图片路径"同名覆盖：
图放到 `assets/resource/resource_win32/image/<与 base 完全相同的相对路径>` 就会替换掉 base 的同名图，
json 里的 `template` 不用改。但**图换了通常也要改 `roi`**，roi 放在
`assets/resource/resource_win32/pipeline/<同路径>` 下同名节点的覆盖文件里。

本清单统计范围：`assets/resource/base/pipeline/往世乐土`、`战斗逻辑`、`乐土自动流程.json`、`商店/乐土商店`。
范围内 `TemplateMatch` 唯一模板图 58 张，其中 6 张已处理或确认可复用（见第一节），剩 52 张列在下面。
`NeuralNetworkDetect`（best.onnx，28 个节点）按你说的不用管，未列出。
